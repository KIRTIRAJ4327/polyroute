# Interviews — recruiting and notes

Track D from `FIRST_SESSION.md`. The 90-day validation plan
(`CLAUDE.md` §8) calls for **20 interviews** in two cohorts:

- **Weeks 1–2**: 10 Pearson commuters
- **Weeks 3–4**: 10 newcomers (international students, recent PRs)

This folder holds the recruiting copy and the structured-notes template.
Anonymized notes go under `docs/interviews/notes/<initials>-<yyyy-mm-dd>.md`
(folder gitignored — see `.gitignore`).

## Files

| File | Purpose |
|---|---|
| `recruiting-posts.md` | Copy-paste posts for Reddit, LinkedIn, Slack, hackathon Discords. |
| `script.md` | The 20-minute interview script from `CLAUDE.md` §8. |
| `notes-template.md` | Structured-notes template — same fields per interview makes synthesis easier. |

## Operational notes

- Interviews are **always opt-in** and **always unpaid** at this stage. If
  someone asks for compensation, the right answer is "not yet — would a
  $10 Tim Hortons card cover it?" Cap at $20.
- Every interview ends with: "Who else should I talk to?" Snowball.
- Notes are personal data. Do not commit raw notes. Synthesis goes into
  `docs/interviews/synthesis-<yyyy-mm>.md` with no PII.
- After each cohort, update `CLAUDE.md` §8 with what was learned.
